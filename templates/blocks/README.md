# Pre-built motion blocks (vendored from the HyperFrames registry)

Official HyperFrames components, kept as modular fragments. A verb template
composes one or more of these with the studio design system (orbs, depth rig,
camera, phases, maxMotion particles).

| Block | Technique |
|-------|-----------|
| bottom-up-letters | Deterministic text splitter — chars rise with back.out overshoot |
| scramble-reveal | Wordmark resolves through a scramble cycle |
| scan-band | Diagonal distortion band + chroma separation over a clean wordmark |

Install more: `npx hyperframes add <name>` in any project, then copy
`compositions/components/<name>.html` here.
